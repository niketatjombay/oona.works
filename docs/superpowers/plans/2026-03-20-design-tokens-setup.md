# Design Token System — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the scaffolded shadcn/Geist defaults with the Oona.Works design token system extracted from Figma — colors, typography, spacing, and radii as CSS custom properties.

**Architecture:** All tokens live in `src/styles/globals.css` as CSS custom properties. Colors and radii are mapped in `@theme inline` for Tailwind utility access. Typography is defined as `@utility` directives for composite classes (size + line-height + letter-spacing + weight). Fonts loaded via `next/font/google` in `layout.tsx`.

**Tech Stack:** Next.js 16.2.0, Tailwind CSS 4, Poppins + Inter (Google Fonts)

**Spec:** `docs/superpowers/specs/2026-03-20-design-tokens-design.md`

```tsx
import type { Metadata } from 'next';
import { Poppins, Inter } from 'next/font/google';
import '@/styles/globals.css';

const poppins = Poppins({
  subsets: ['latin'],
  weight: ['400', '500', '600'],
  display: 'swap',
  variable: '--font-poppins',
});

const inter = Inter({
  subsets: ['latin'],
  display: 'swap',
  variable: '--font-inter',
});

export const metadata: Metadata = {
  title: 'Create Next App',
  description: 'Generated by create next app',
};

export default function RootLayout({
  children,
}: Readonly<{
  children: React.ReactNode;
}>) {
  return (
    <html
      lang="en"
      className={`${poppins.variable} ${inter.variable} h-full antialiased`}
    >
      <body className="flex min-h-full flex-col">{children}</body>
    </html>
  );
}
```
